# results/

Generated by the pipeline (see `../instructions.md`). All files here come
from a real training/evaluation run -- nothing is simulated or hardcoded.

| File | Produced by |
|---|---|
| `experiment_log.csv` | every script (`run_baseline.py`, `run_mogeo.py`, `run_final.py`) |
| `mogeo_results.csv` | `run_mogeo.py` -- one row per evaluated MOGEO candidate |
| `best_hparams.json` | `run_mogeo.py` -- selected best-compromise hyperparameters |
| `mogeo_convergence.png` | `run_mogeo.py` |
| `baseline_training_curves.png` | `run_baseline.py` |
| `training_curves.png` | `run_final.py` |
| `accuracy_report.md` / `.json` | `evaluate_final.py` (final_test, evaluated once) |
| `confusion_matrix.png` | `evaluate_final.py` |
| `error_analysis.md` | `evaluate_final.py` |
